# AI-Friendly README: ESP32 Smart BMS Station

## 🤖 دستورالعمل‌های حیاتی برای هوش مصنوعی (AI Developer Instructions)
این پروژه یک سیستم مدیریت و پایش باتری (BMS) مبتنی بر ESP32 است که برای محیط Arduino IDE توسعه یافته و به صورت ماژولار (چند فایلی) ساختاربندی شده است. 

هنگام دریافت درخواست ویرایش، دیباگ یا افزودن قابلیت جدید از سمت کاربر، **باید** قوانین زیر را به دقت رعایت کنید:

### ⚠️ قانون طلایی ویرایش (The Golden Rule)
به دلیل پیوستگی متغیرهای سراسری (Global Variables) بین فایل‌های `.ino`، اگر توسعه یا رفع باگ نیازمند درک یا تغییر کدهای بیش از یک فایل است، **به هیچ وجه محتوای فایل‌های دیگر را حدس نزنید و کد کورکورانه تولید نکنید.** 
در این شرایط، موظف هستید دقیقاً نام فایل‌های مورد نیاز را به کاربر بگویید و از او درخواست کنید تا ابتدا کدهای آن فایل‌ها را برایتان ارسال کند. پس از دریافت و بررسی دقیق ساختار فعلی، تغییرات را اعمال کنید.

## 📂 معماری و وظایف فایل‌های پروژه
تمامی فایل‌های با پسوند `.ino` هنگام کامپایل به صورت خودکار توسط آردوینو به هم متصل می‌شوند و متغیرهای سراسری فایل اصلی را می‌شناسند. 

*   **`Battery-Station.ino` (فایل اصلی)**
    *   شامل تعریف اشیاء اصلی (مثل `server`, `display`, `ina3221`).
    *   شامل تعریف تمامی متغیرهای سراسری سیستم.
    *   حاوی توابع `setup()` و `loop()` و خواندن ریموت RF.
*   **`Config.h`**
    *   فایل هدر حاوی تمامی ماکروها (`#define`).
    *   شامل پین‌های سخت‌افزاری، مقاومت‌های شنت، آدرس‌های I2C، ولتاژهای کالیبراسیون و اطلاعات WiFi.
*   **`WebPanel.h`**
    *   فایل هدر منحصراً برای نگهداری رابط کاربری وب (HTML/CSS/JS).
    *   متغیر متنی `INDEX_HTML` در این فایل با دستور `PROGMEM` در حافظه فلش ذخیره شده است تا RAM را اشغال نکند.
*   **`WebHandlers.ino`**
    *   هندلرهای وب‌سرور شامل توابعی مانند `handleRoot`، `handleData`، `handleRelay` و `handleChargerConfig`.
    *   *(نکته برای AI: اگر فیلد جدیدی به دیتای JSON اضافه می‌کنید، علاوه بر این فایل باید HTML فایل `WebPanel.h` را نیز برای نمایش درخواست کنید).*
*   **`Charger.ino`**
    *   توابع کنترلر هوشمند شارژ باتری از طریق پروتکل I2C برای آی‌سی IP2365 (`manageIP2365`).
*   **`Sensors.ino`**
    *   توابع خواندن داده‌ها از آی‌سی INA3221 (ولتاژ، جریان، توان) و سنسورهای دمای DS18B20.
*   **`Display.ino`**
    *   توابع مربوط به رندر و نمایش اطلاعات روی ماژول OLED (`updateOLED`).

## 🛠 وابستگی‌های سخت‌افزاری و کتابخانه‌ها (Dependencies)
هنگام پیشنهاد کدهای جدید، در نظر داشته باشید که پروژه از کتابخانه‌های زیر استفاده می‌کند:
*   `WiFi.h` & `WebServer.h` (مدیریت شبکه و پنل لوکال)
*   `Wire.h` (ارتباط I2C در فرکانس 100kHz)
*   `Adafruit_GFX.h` & `Adafruit_SSD1306.h` (نمایشگر OLED با آدرس 0x3C)
*   `INA3221.h` (پایش ۳ کاناله جریان/ولتاژ با آدرس 0x41)
*   `OneWire.h` & `DallasTemperature.h` (سنسورهای دما روی یک باس مشترک)
